# AI Subak Game

같은 단계의 과일 캐릭터를 합쳐 더 높은 단계와 최고 점수를 노리는 세로형 물리 퍼즐 게임입니다. 기존 수박게임 방식에 **흔들기 스킬**과 **코인 경제**를 더해, 쌓인 과일을 정리하고 막힌 판을 풀어내는 선택지를 확장했습니다.

[브라우저에서 플레이하기](https://ai-subak-game.goldbatne.chatgpt.site)

## 게임 방법

| 조작 | 방법 |
|---|---|
| 과일 이동 | 마우스 또는 손가락으로 대기 중인 과일의 좌우 위치를 조절합니다. |
| 과일 놓기 | 게임 영역을 클릭하거나 탭합니다. |
| 합체 | 같은 단계의 과일이 닿으면 다음 단계 과일로 합쳐집니다. |
| 흔들기 | `Shake` 버튼을 눌러 바구니 안의 과일에 힘을 가합니다. |
| 스킬 구매 | 합체로 얻은 코인 20개를 사용해 흔들기 횟수를 구매합니다. |

별도 로그인이나 설치 없이 데스크톱과 모바일 브라우저에서 플레이할 수 있습니다. 세로 화면에 맞춰 설계되어 모바일에서는 화면을 세로로 두는 것을 권장합니다.

## 핵심 시스템

| 시스템 | 설명 |
|---|---|
| 과일 합체 | 같은 단계끼리 충돌하면 다음 단계로 성장하며 점수와 코인을 얻습니다. |
| 11단계 사다리 | 작은 과일부터 최종 단계까지 크기와 질량이 단계별로 증가합니다. |
| NEXT 표시 | 다음에 등장할 과일을 미리 확인할 수 있습니다. |
| 흔들기 스킬 | 과일에 아래쪽·중앙 방향의 질량 보정 힘을 적용해 배치를 바꿉니다. |
| 코인 경제 | 합체 점수에 따라 코인을 얻고, 코인으로 흔들기 횟수를 구매합니다. |
| 데드존 | 과일이 상단 제한선을 일정 시간 넘으면 게임이 종료됩니다. |
| 최고 점수 | 브라우저의 로컬 저장소에 기기별 최고 점수를 기록합니다. |

## 웹 이식

이 프로젝트는 기존 Unity 기반 APK 게임을 분석한 뒤, 브라우저에서 바로 실행되도록 HTML5 웹 버전으로 재구현한 결과물입니다. Unity 프로젝트의 과일 단계, 크기, 질량, 합체 규칙, 데드존, 흔들기 스킬, 코인 시스템을 파일 기준으로 정리하고 Matter.js 물리 엔진에 맞게 옮겼습니다.

웹 이식 과정에서는 다음 작업을 새롭게 진행했습니다.

- Unity 물리 규칙을 Matter.js 기반 충돌·합체 로직으로 재구성
- 마우스와 터치 입력을 함께 지원하는 세로형 웹 인터페이스 제작
- 과일 크기와 등장 범위, NEXT 표시, Option/Shop/Shake UI 조정
- 합체 효과와 물리 반응, 데드존 카운트다운 및 메시지 출력 구현
- 모바일 화면에서 게임과 조작 안내를 함께 확인할 수 있도록 반응형 레이아웃 구성
- 브라우저 최고 점수 저장과 공개 웹 배포 구성

흔들기 스킬은 웹 물리 엔진에서 움직임이 과하거나 약하지 않도록 반복적으로 조정했으며, 최종적으로 Unity 원본의 의도에 가까운 아래쪽·중앙 방향 움직임을 사용합니다.

## 로컬 실행

Node.js 22 이상을 권장합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령으로 생성합니다.

```bash
npm run build
npm run preview
```

## 프로젝트 구조

```text
public/assets/       과일, UI, 사운드 에셋
src/main.ts          게임 규칙, 물리, 입력, 상태 관리
src/styles.css       게임 화면과 반응형 레이아웃
index.html           게임 UI 구조
analysis.md          Unity 원본 파일 기반 이식 분석 보고서
```

## Codex와의 개발 과정

Codex를 활용해 Unity 프로젝트의 실제 설정값을 조사하고 웹 이식 사양을 정리했습니다. 이후 구현 결과를 원본 플레이 화면과 반복적으로 비교하면서 과일 크기와 등장 범위, UI 배치, 메시지 표시, 합체 후 물리 반응, 흔들기 힘, 메인 화면 사운드 상태를 조정하고 브라우저 배포까지 진행했습니다.

## 참고 사항

- 이 저장소에는 HTML5 웹 버전이 포함되어 있으며 기존 Unity 프로젝트 전체는 포함하지 않습니다.
- 최고 점수는 서버 계정이 아니라 현재 브라우저에 저장되므로, 브라우저 데이터 삭제·시크릿 모드·다른 기기 사용 시 초기화될 수 있습니다.
- 저장소가 공개되어 있어도 별도 라이선스가 명시되지 않은 코드와 에셋의 사용 권한이 자동으로 부여되는 것은 아닙니다.
